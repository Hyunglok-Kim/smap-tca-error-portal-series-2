# smap-tca-error-portal-series-2

Browse data of the SMAP time-variant soil-moisture error portal (Kim et al. 2025, GIScience & Remote Sensing, doi:10.1080/15481603.2025.2475572): gzipped per-cell series (uint16) in PMTiles archives, read over HTTP range requests by https://hyunglok-kim.github.io/smap-tca-error-portal/ . Not for analysis: use the NetCDF files (2022: https://doi.org/10.5281/zenodo.14850520; other years on request, hyunglokkim@gist.ac.kr). CC BY 4.0, please cite the paper.
